# 8 周学习配套阅读资料

> 配合 [LEARNING_8_WEEK_CHECKLIST.md](/d:/lixy/AI/langchain-starter/project/LEARNING_8_WEEK_CHECKLIST.md) 使用  
> 原则：每周只补和当前阶段强相关的资料，不贪多

---

## 使用建议

- 每周阅读控制在 `2-4 小时` 内。
- 先做仓库里的代码练习，再看外部资料。
- 阅读目标不是“看完”，而是解决你当前这周正在做的问题。
- 每看完一份资料，至少回答两个问题：
  - 这份资料帮我解决了什么？
  - 我可以把其中哪一条思路落到当前仓库里？

## 第 1 周：最小调用、Prompt、多轮对话

### 本周重点

- 理解 LLM 最小调用链路
- 理解 system prompt / user prompt
- 理解多轮对话的本质

### 推荐阅读

1. LangChain 官方文档：Chat models
   - 重点看：如何初始化聊天模型、如何调用、消息格式是什么
   - 用途：帮助你看懂 `project/01/hello.py`

2. LangChain 官方文档：Prompt templates
   - 重点看：`ChatPromptTemplate`
   - 用途：帮助你看懂 `project/02/basic_chat.py`

3. LangChain 官方文档：Messages
   - 重点看：system / human / ai message 的角色区别
   - 用途：帮助你理解多轮对话为什么只是“消息列表”

### 本周带着问题去看

- 为什么 prompt 模板比字符串拼接更适合后续扩展？
- 多轮对话为什么不是单独的“高级功能”？
- 如果历史消息越来越长，会带来什么副作用？

### 本周阅读产出

- 一页笔记：什么是 message、prompt template、invoke

---

## 第 2 周：代码结构与小应用

### 本周重点

- 学会抽公共函数
- 学会组织小型 LLM 应用代码
- 开始意识到“纯 prompt 模式”的边界

### 推荐阅读

1. LangChain 官方文档：Quickstart
   - 重点看：最小应用结构
   - 用途：对照你自己写的小脚本，看哪些地方还能整理

2. LangChain 官方文档：Runnables / LCEL 基础
   - 重点看：`invoke`、链式组合
   - 用途：先建立概念，不要求这一周完全吃透

3. 一篇你自己认可的“Prompt Engineering 基础总结”
   - 重点看：角色设定、输出格式约束、少样本示例
   - 用途：提升你写 prompt 的稳定性

### 本周带着问题去看

- 什么时候应该抽函数，什么时候先别过度抽象？
- 为什么很多 demo 能跑，但不容易维护？
- 如果要把脚本继续扩展成 RAG / Agent，哪些部分现在就该留接口？

### 本周阅读产出

- 一份你自己的“小应用代码结构原则”

---

## 第 3 周：RAG

### 本周重点

- 理解 RAG 整体链路
- 理解 chunk、embedding、retriever、top-k
- 学会从“知识质量”看回答质量

### 推荐阅读

1. LangChain 官方文档：Retrieval
   - 重点看：retriever 的作用
   - 用途：帮助你理解 `project/03/rag_qa.py`

2. LangChain 官方文档：Document loaders
   - 重点看：如何加载本地文档
   - 用途：帮助你扩展 FAQ 以外的资料格式

3. LangChain 官方文档：Text splitters
   - 重点看：为什么要分块、如何调 chunk size
   - 用途：帮助你做参数实验

4. FAISS 基础介绍
   - 重点看：向量检索在做什么
   - 用途：帮助你理解本地向量库不是“黑盒”

### 本周带着问题去看

- 为什么有些问题明明知识库里有，还是答不好？
- chunk 太大和太小分别会带来什么问题？
- embedding 模型和聊天模型分别负责哪一步？

### 本周阅读产出

- 一份“RAG 失败原因分类”

---

## 第 4 周：Tools 与单 Agent

### 本周重点

- 理解 Tool 的本质
- 理解 Agent 如何选择工具
- 学会设计更适合模型调用的函数接口

### 推荐阅读

1. LangChain 官方文档：Tools
   - 重点看：tool 的定义、描述文本、参数设计
   - 用途：帮助你理解 `project/04/tools_agent.py`

2. LangChain 官方文档：Agents
   - 重点看：agent 的运行逻辑
   - 用途：帮助你理解“模型不是直接回答，而是在决策是否调用工具”

3. 1-2 个 GitHub 上的简洁 tools-agent 示例
   - 重点看：别人怎么设计工具说明、返回值和异常处理
   - 用途：对照你自己的工具设计

### 本周带着问题去看

- 为什么工具描述写不好，会直接影响工具选择？
- tool 返回给模型的内容应该“像给人看”，还是“像给机器继续处理”？
- agent 选错工具时，最常见的问题出在哪？

### 本周阅读产出

- 一份“好 tool 的 5 条标准”

## 第 5 周：客服 Agent 原型

### 本周重点

- 把 RAG Tool 和业务 Tool 组合起来
- 学会从业务问题分类角度看 Agent
- 形成回归测试题集意识

### 推荐阅读

1. 重读你自己的 [cust_service_agent_cli.py](/d:/lixy/AI/langchain-starter/project/05/cust_service_agent_cli.py)
   - 重点看：FAQ、订单、物流三类能力的组合方式

2. 1-2 个客服/FAQ 类 GitHub Demo
   - 重点看：问题路由、知识库使用、兜底回复策略
   - 用途：学习别人如何做“像业务”的 demo

3. Prompt 设计相关文章
   - 重点看：如何约束“不能乱编”“信息不足时要诚实”
   - 用途：优化客服风格和稳定性

### 本周带着问题去看

- 客服 Agent 和普通聊天助手最大的差别是什么？
- 哪类问题应该优先交给 RAG，哪类问题应该优先交给 Tool？
- 如何让回复更像客服，而不是像百科机器人？

### 本周阅读产出

- 一份“客服场景问题路由表”

## 第 6 周：Memory 与状态

### 本周重点

- 理解多轮状态在业务场景中的价值
- 学会区分“聊天历史”和“业务状态”
- 开始接触 session / state 思维

### 推荐阅读

1. LangChain 官方文档：Chat history / memory 相关内容
   - 重点看：会话历史如何维护
   - 用途：帮助你改造客服 Agent 的多轮体验

2. 如果开始接触 LangGraph
   - 重点看：state 的概念
   - 用途：先建立“状态图”意识，不要求本周深入实现

3. 1 篇关于对话状态管理的文章
   - 重点看：订单号、用户意图、槽位信息这类“业务状态”
   - 用途：帮助你区分“记住消息”与“记住关键字段”

### 本周带着问题去看

- 为什么只保存历史消息还不够？
- 什么时候需要记住“当前订单号”这种结构化状态？
- memory 太多为什么会污染上下文？

### 本周阅读产出

- 一份“聊天历史 vs 业务状态”对照表

## 第 7 周：API 与前端

### 本周重点

- 把脚本封装成服务
- 理解 session_id、trace、日志
- 理解最小聊天前端如何接后端

### 推荐阅读

1. FastAPI 官方入门
   - 重点看：`GET`、`POST`、请求体、响应模型
   - 用途：帮助你看懂 `project/06/api_server.py`

2. FastAPI 文档：Pydantic request/response model
   - 重点看：接口输入输出约束
   - 用途：帮助你从“脚本参数”过渡到“API contract”

3. Vue 或当前前端栈基础
   - 重点看：输入框、请求发送、状态显示
   - 用途：帮助你看懂 `project/07/web_ui/src/App.vue`

4. 基础日志和 trace 概念资料
   - 重点看：为什么要有 trace_id
   - 用途：帮助你理解调试线上问题时为什么不能只看终端输出

### 本周带着问题去看

- 为什么 API 层要管理 `session_id`？
- 为什么 Demo 一旦变成服务，就要关注日志和追踪？
- 聊天前端最小闭环包含哪些交互状态？

### 本周阅读产出

- 一份“CLI -> API -> Web UI 的链路说明”

## 第 8 周：评估与进阶方向

### 本周重点

- 形成测试集意识
- 理解 Agent 评估为什么重要
- 明确下一阶段学习路线

### 推荐阅读

1. 重读 `tests/cases.json`
   - 重点看：测试集结构、问题分类、预期结果组织方式

2. 重读 `project/eval/eval_cust_service.py`
   - 重点看：如何批量调用 agent、如何记录结果

3. 一篇关于 LLM / Agent evaluation 的入门资料
   - 重点看：为什么评估不只看“答得像不像”
   - 用途：帮助你理解准确性、稳定性、覆盖率

4. LangGraph / OpenAI Agents SDK / AutoGen 的官方概览
   - 重点看：这三个方向各自适合什么场景
   - 用途：为下一阶段做选择

### 本周带着问题去看

- 一套测试题为什么比几次手工演示更有价值？
- 什么样的失败适合通过 prompt 修，什么样的失败需要改 tool / RAG？
- 下一阶段我更需要“流程编排”还是“多 Agent 协作”？

### 本周阅读产出

- 一份“下一阶段框架选型理由”
