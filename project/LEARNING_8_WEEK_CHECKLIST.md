# 8 周 AI Agent 学习打卡表

> 适用对象：基于当前仓库 `langchain-starter` 学习 LangChain 1.0 / RAG / Tools / Agent / API / Eval  
> 学习节奏：每天 2 小时，建议每周学习 6 天，1 天机动复盘  
> 学习目标：8 周后，能够独立完成一个可演示、可评估的客服 Agent 原型

---

## 使用方法

- 每天固定 2 小时，尽量不要拆得太碎。
- 每次学习尽量遵循这个节奏：
  - `20 分钟`：读现有代码
  - `40 分钟`：改代码或自己重写
  - `30 分钟`：做测试输入
  - `20 分钟`：记录问题和结论
  - `10 分钟`：写第二天的待验证点
- 每天至少留下一个“看得见的产出”：
  - 一段自己改过的代码
  - 一组测试问题
  - 一份简短学习笔记
  - 一个失败案例记录

---

## 学习总目标

- 第 1-2 周：掌握模型调用、Prompt、多轮对话基础
- 第 3 周：掌握 RAG 基础链路
- 第 4 周：掌握 Tools 和单 Agent
- 第 5 周：完成客服 Agent CLI 原型
- 第 6 周：补 Memory 和多轮状态
- 第 7 周：打通 API 和前端
- 第 8 周：完成评估、复盘和下一阶段规划
